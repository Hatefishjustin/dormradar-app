# 宿管微波雷达检测系统（代号 DormRadar）

> **这是一个什么项目**：围绕 HLK-LD2410C 毫米波人体存在感应雷达开发的 Android App。
> 它既是设备的控制工具，也是监控工具、调试工具和部署辅助工具。
> 本仓库目前处于 **「工程骨架已建、阶段 0 收尾」** 阶段（协议层+单测已就绪，待首次编译验证）。

---

## 30 秒了解这个项目

- **硬件**：HLK-LD2410C 24GHz 毫米波雷达模组，通过 BLE 蓝牙与手机通信（串口协议透传）。
- **部署场景**：设备 USB 供电，安装在寝室门板内侧、朝向走廊，检测门外有人经过/停留/活动；检测到人体时设备 OUT 引脚驱动 LED 亮起。
- **App 目标**：
  1. 完整复刻官方 App（HLKRadarTool）的全部设备能力（配置、实时数据、工程模式、底噪检测、固件信息等）；
  2. 在体验上超越官方 App：更现代、更适合调试与长期部署；
  3. 核心增量能力：**后台持续监控 + 本地消息通知**（有人经过、设备异常、连接断开等事件直接推送到手机，无需打开 App）。

## 技术决策速览（详细理由见决策记录）

| 领域 | 决策 |
|---|---|
| 平台 | 原生 Android（Kotlin），不用跨端框架 |
| UI | Jetpack Compose + Material 3，单 Activity |
| 架构 | MVVM + 单向数据流，Hilt 依赖注入，协程 + Flow |
| 工程结构 | 单 Gradle 模块 + 严格包分层；协议解析层零 Android 依赖、可纯单测 |
| 通知 | 纯本地通知（设备 BLE 直连，无需服务器/FCM） |
| 后台保活 | 前台服务（connectedDevice 类型）为主，WorkManager 兜底 |
| 存储 | Room（事件/设备/配置快照）+ DataStore（设置） |
