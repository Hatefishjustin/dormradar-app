## 4. 技术栈与架构速览

- 原生 Android + **Kotlin 2.0.21** + Jetpack Compose (BOM 2024.10.01) + Hilt 2.52 + Room 2.6.1 + DataStore；minSdk 26 / targetSdk 35；单模块 + 严格包分层。
- **core/protocol 零 Android 依赖**（帧编解码 + 黄金测试），core/monitor、core/deploy、core/log 的核心逻辑同为纯 Kotlin 可 JVM 单测。
- 核心链路：`BleClient`(GATT 薄封装/串行队列/指数退避重连) → `RadarConnection`(@Singleton 连接编排+全部配置 API+帧日志挂点) → `RadarMonitorService`(前台服务 connectedDevice+START_STICKY) → `Notifier`(三渠道本地通知) + Room 事件流水。
- 包结构：`core/{protocol,ble,device,data,monitor,notification,log,deploy}` + `service/` + `feature/{home,events,settings,config,quicksetup,logs,deploy}` + `ui/AppRoot`（底部 3 Tab + 详细设置子路由）。
- 模拟设备：设置里开「模拟数据」可无硬件体验全部功能（FakeRadarSource 生成真实协议字节流）。

## 5. 设备协议关键事实（浓缩版，细节见 docs/03）

- BLE 服务 `0000fff0-...`；**fff1=Notify（设备→手机）、fff2=Write Without Response**；MTU 请求 247。
- 连接后**必须先发蓝牙密码 0x00A8**（默认 `HiLink`）才透传。
- 命令帧头 `FD FC FB FA` / 尾 `04 03 02 01`；上报帧头 `F4 F3 F2 F1` / 尾 `F8 F7 F6 F5`；**全小端**。
- 配置命令必须包在 `0x00FF 使能配置 … 0x00FE 结束配置` 之间；ACK 命令字 = 原命令字 | 0x0100。
- 本机固件 1.00.68：**0x0061 响应首字节后是最大门（恒 8），不是运动门**（曾栽过）；底噪检测进度靠上报帧目标状态 0x04/05/06；近门（0/1）静止灵敏度部分固件不可写（代码已容错）。
- 蓝牙关了恢复不了：2~3 秒内断电重上电 5 次。广播名 `HLK-LD2410_<MAC末4位>`。

## 6. 构建环境（本机已就绪，勿重装）

- JDK 17 + SDK 在 `D:\Android\Sdk`（**adb 不在 PATH**，用 `D:\Android\Sdk\platform-tools\adb.exe`）。
- **仓库路径含中文，必须先 `subst X: "D:\Github\宿管微波雷达检测系统"` 再从 `X:\` 构建**（否则 JVM 单测 ClassNotFound）。
- 命令：`X:\gradlew.bat testDebugUnitTest assembleDebug --console=plain`（**PowerShell 5.1 不认 `&&`，用 `;`**）。APK 在 `app/build/outputs/apk/debug/`。
- KSP daemon 偶发崩溃 → `gradlew --stop` 重跑。
- 手机连电脑后装机：`adb install -r X:\app\build\outputs\apk\debug\app-debug.apk`（MIUI 弹窗需用户点允许）。

## 8. 协作硬规则（违反会破坏可交接性）

1. **docs/01~08 是权威**；代码与文档冲突先改文档再改代码；重大决策 → docs/07 追加 ADR；
2. 每次会话结束前更新 docs/08（进度/下一步/问题销项）；
3. 不引入文档未记录的第三方依赖（尤其网络类——本项目无云无账号）；
4. 禁止 `npm audit fix --force` 类破坏性操作；禁止提交 token/keystore；禁止手动改线上数据；
5. 全部中文（文档/注释/提交信息）；

7. MIUI 会丢 Log.d/Log.v，关键日志必须 Log.i 及以上（core/log 的 LogStore 已统一处理）。
