## 1. 硬件规格

| 项目 | 参数 |
|---|---|
| 型号 | HLK-LD2410C（HLK-2410C 为同一模组的简写） |
| 射频 | 24GHz ISM（24–24.25GHz），FMCW 调制，1 发 1 收 |
| 探测能力 | 存在检测最远约 6m；运动检测最远约 8m；探测角度 ±60° |
| 距离分辨率 | 每距离门 0.75m（默认）或 0.2m（新固件可选），最多 8 个距离门 |
| 供电 | 5V（建议供电能力 >200mA），工作电流约 79mA；模块会发热（正常现象） |
| IO 电平 | 3.3V |
| 串口 | UART TTL，**默认波特率 256000**，8N1 |
| 蓝牙 | BLE（从机，仅允许单连接），默认开启 |
| 其他 | 部分固件/板型带光敏传感器（"光敏固件"），待实机确认本项目板子是否支持 |

### 引脚定义

| 引脚 | 符号 | 功能 |
|---|---|---|
| 1 | OUT | 目标状态输出：有人高电平，无人低电平（**用户的 LED 就接在这里**） |
| 2 | UART_Tx | 串口发送 |
| 3 | UART_Rx | 串口接收 |
| 4 | GND | 地 |
| 5 | VCC | 5V 输入 |

### 本项目部署方式

- USB 供电（只供电，不走数据）；
- 安装在寝室门板内侧，天线面朝向走廊；
- LED 接 OUT 引脚做本地指示，与 App 互不依赖。

## 2. 通信方式总览

App 与设备通信**只走 BLE**。BLE 上跑的就是串口协议（官方说明书原文："蓝牙透传的数据与串口协议完全相同"）。串口（USB 转 TTL）仅作为开发期的调试备用通道。

### BLE 规范（关键）

| 项目 | 值 | 来源 |
|---|---|---|
| 角色 | 从机（Slave），**同一时刻只允许一个主机连接** | 官方说明书 6.5 |
| 特征 UUID（Notify，设备→手机） | `0000fff1-0000-1000-8000-00805f9b34fb`（Read/Notify） | 官方说明书 6.5 |
| 特征 UUID（Write，手机→设备） | `0000fff2-0000-1000-8000-00805f9b34fb`（Write Without Response） | 官方说明书 6.5 |
| 服务 UUID | `0000fff0-0000-1000-8000-00805f9b34fb` | 官方 Demo 源码确认 |
| 广播名 | 待实机确认（扫描时按 `fff0` 服务 UUID 过滤即可，不依赖广播名） | — |
| 鉴权 | 连接后 App 必须先发**校验密码命令 `0x00A8`**（默认 `HiLink`，区分大小写），通过后才透传雷达数据 | 官方 Demo `checkKeyByPwd` |
| MTU | 官方 Demo 主动 `requestMtu(247)`；协商成功单包约 244 字节，**仍须流式重组**（防粘包/半包） | 官方 Demo `BluetoothLeClass` |

### 连接时序（官方 Demo `BluetoothLeClass.java` 实证）

1. `connectGatt(autoConnect=false)`；
2. `onServicesDiscovered` → 在 `fff0` 服务下找到 `fff1`（Notify）与 `fff2`（Write）两个特征，任一缺失即断连；
3. 对 `fff1` 执行 `setCharacteristicNotification(true)` + `writeDescriptor(ENABLE_NOTIFICATION_VALUE)`；
4. 写类型固定 `WRITE_TYPE_NO_RESPONSE`；
5. 请求 MTU=247（失败则退回默认值，不影响功能）；
6. 上层收到"连接成功"后，第一件事发送 `0x00A8` 校验密码（默认 `HiLink`）。

### 蓝牙恢复机制（重要运维知识）

- 蓝牙默认开启，可用串口命令 0x00A4 关闭；
- 若蓝牙被关闭且无法通过串口恢复：**在 2~3 秒内断电重上电 5 次以上**，蓝牙会重新开启（官方说明书 6.6）。App 应在"设备找不到了"的引导页中教用户这个操作。

## 4. 部署相关的物理知识（直接影响调参与通知质量）

- **穿门探测**：毫米波可穿透木板/塑料等非金属材质；金属门、金属贴膜会严重屏蔽。寝室木门场景可行，但门板会衰减能量 → 灵敏度需要按"穿门后的实际能量"来调，这正是工程模式+底噪检测的用途；
- **误报源**：风扇、空调出风、窗帘、绿植摆动、门外金属物体震动；通过"底噪检测→按底噪值抬高灵敏度阈值"来抑制；
- **方向屏蔽**：把面向房间内的距离门灵敏度设为 100（即禁用该距离门），可避免自己在屋内走动触发门外告警；
- **无人持续时间**：决定"人离开后多久判定为无人"，影响 LED 熄灭延迟与"离开"通知的时机，默认 5s；
- **安装角度**：±60° 覆盖，正对走廊轴线效果最佳；高度建议 1~1.5m（与人体躯干对齐），待实机调整；
- **上报频率**：有目标时约 1 次/秒（不同固件/模式可能有差异，待实测）。
