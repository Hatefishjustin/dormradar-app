# HLK-LD2410C APP 功能全量复刻清单（V2.0 详细版）

> 依据：官方说明书 V1.09、官方串口通信协议 V1.07（2024-08-05）、官方 APP（HLKRadarTool）公开资料

## 一、设备是什么（能力底座）

| 项目 | 规格 |
|---|---|
| 芯片方案 | HLK-LD2410C-24G，24GHz 毫米波雷达，FMCW |
| 探测能力 | 同时检测运动目标 + 静止目标（呼吸级微动），0.75m~6m（可切 0.2m 分辨率） |
| 距离门 | 最多 8 个距离门 |
| 无线接口 | BLE 5.1（默认开启），UART 透传同一套串口协议 |
| 蓝牙特征值 | `fff1`（Notify 上报）/ `fff2`（Write 下发命令） |
| 默认蓝牙密码 | HiLink |
| 串口 | 默认 256000bps，8 档可调（9600~460800） |
| 引脚 | UART_Tx / UART_Rx / OUT（有人高电平）/ GND / VCC(5V) |

**底层事实（决定功能上限）**：BLE 通道本质是串口协议透传，APP 能做什么 = 协议命令全集能做什么。下面每一类功能都对应可执行的协议命令。

**数据上报帧**（模块上报，APP 解析）：
- 帧头 F4 F3 F2 F1 + 长度 + 类型（0x01 工程 / 0x02 基本）+ 0xAA + 目标数据 + 0x55 0x00 + 帧尾 F8 F7 F6 F5
- 基本数据：目标状态(1B) + 运动距离(2B) + 运动能量(1B) + 静止距离(2B) + 静止能量(1B) + 检测距离(2B)
- 工程数据追加：最大运动门 + 最大静止门 + 运动各门能量(0~8) + 静止各门能量(0~8) + 光敏值 + OUT 状态
- 目标状态值：0x00 无 / 0x01 运动 / 0x02 静止 / 0x03 运动+静止 / 0x04 底噪检测中 / 0x05 底噪成功 / 0x06 底噪失败
